# 🧾 AutoDoc - Gerador de Termos Automático

O **AutoDoc** é uma aplicação em Python com interface moderna desenvolvida em **CustomTkinter** que automatiza a geração de documentos do Word (`.docx`).  
Com ele, é possível preencher um modelo de termo com dados como **nome, CPF, RG, endereço, data e série**, e gerar automaticamente um arquivo formatado.

---

## ⚙️ Funcionalidades

- Interface moderna e modo escuro 🖤  
- Preenchimento automático de **CPF** e **RG** com formatação  
- Seleção de **data por calendário interativo**  
- Escolha de **modelo de documento** diretamente da pasta `docs`  
- Opção de **salvar automaticamente** com nome padrão (`Termo_NomePessoa.docx`)  
- Consulta automática de endereço via **CEP (API ViaCEP)**  
- Compatível com **Windows** e **Linux**

---

## 📦 Dependências

O projeto utiliza as seguintes bibliotecas Python:

- customtkinter
- tkcalendar
- python-docx
- requests


Você pode instalar todas elas com:

bash
pip install -r requirements.txt
